What is deliberately not happening

No oscillator and no generated waveform — the sound is decoded PCM from a recording. No attack/sustain/release envelope, no filter, no gain node, no trim, no normalisation, no loop points, and nothing is ever stopped: each note makes a new AudioBufferSourceNode that plays the file out and is left alone. The only thing the player decides is which recorded note to play and which hammer struck it.
